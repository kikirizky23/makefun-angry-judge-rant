A short, furious rant about a neighbour's leaf blower: **"My neighbour fires up his leaf blower every Saturday at 7am to move three leaves from his driveway onto mine. Six years, same three leaves, they never leave. He is not cleaning anything. He is watering the leaves with noise while the rest of us lie there pretending Saturday morning is still a real thing."** The gag is a ritual that never works — the same three leaves, six years running, and the chore reframed as watering leaves with noise. The program writes this one rant (305 characters) to `/output/entry.txt` and nothing else: one paragraph, no extra words, no trailing newline.

## Run it

```sh
node main.ts
```

It makes the output folder when it is missing, writes `/output/entry.txt` as UTF-8 (one paragraph, no trailing newline), then reads the file back to make sure it holds exactly the rant above.
